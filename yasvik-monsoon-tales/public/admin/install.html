Install Yasvik Admin

For product photos & store control on iPhone — not the customer shop app.

Important: Add to Home Screen from this page. If you add from the shop homepage, iPhone saves yasvik.com/ and you cannot change it.
  1. Stay on this page in Safari (not Chrome, not the shop icon).
  2. Tap Share → Add to Home Screen.
  3. Confirm the name is Yasvik Admin → Add.
  4. Open the new icon → log in → add product photos.
