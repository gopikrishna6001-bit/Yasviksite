# Catalogue Manager — Simple workbook baseline

Owner-facing export is **`YASVIK_CATALOGUE_SIMPLE.xlsx`** (5 sheets).

| Sheet | Role |
|---|---|
| START_HERE | Workflow, colour guide, live issue counts, image naming |
| PRODUCTS | One row per product — business fields only |
| PACKS_PRICING | One row per pack — costs + selling + MRP + Excel checks |
| BATCH_LABELS | Occasional batch / label inputs |
| SETTINGS | Margins, packaging costs, lists |

Not exported to the owner: UUIDs, SEO sheets, MEDIA URLs/R2 keys, shipping weight, sort order.

Images: ZIP named `<PRODUCT_CODE>_hero.webp`, `_2.webp`, `_3.webp` (Phase 3 upload).

Import / publish remains Phase 2.
